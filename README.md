# 梁仓存取看板

按 Notion《制梁需求》PRD v0.5 和交互稿 v0.4 实现的项目管理与存梁棋盘。设备 MQTT 协议还没定，这一版不连接 Broker，也不向客户发请求。存取用虚拟数据验证。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

默认管理员：`admin` / `admin123`

## 这一版怎么处理上报

页面读的是内存里的棋盘快照。虚拟上报先进入内存队列，再按小批量写入数据库，同一位置在一个批次里按顺序加减层数。以后设备协议确定后，只需要把报文转成同一条上报再入队，不要在接收回调里改棋盘或调用客户接口。

测试模式每个项目同时只有一个计时器：打开后立刻生成 1 条，之后按所选间隔生成，默认每 20 秒 1 条，写在测试沙箱里。服务重启不会自动恢复测试。
